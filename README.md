# mental models

Short explanations of how backend and infra systems behave, each with one interactive simulation. Astro + React.

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build
```

An entry is four files: prose in `src/content/models/<id>.mdx`, the event model in `src/models/<id>.ts`, the picture in `src/components/scenes/<Id>Scene.tsx`, and design notes in `docs/entries/<id>.md`.
